# Portfolio

A personal project showcase hosted on GitHub Pages.

https://jenny-jw.github.io/portfolio/

## Scope

- Static HTML, CSS, and JavaScript
- A hand-maintained list of 4–6 projects
- Each entry includes a name, a one-line summary, tech tags, and a GitHub link. Include a demo link only when a public demo exists.
- Static assets use relative paths

## Publishing

- GitHub Pages source: `master` branch root, entry point `index.html`
- Set a page title, a short introduction, and a favicon
- Keep the layout readable on a phone
- Link only public projects, with no secrets or credentials
